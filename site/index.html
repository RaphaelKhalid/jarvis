Build a robot that actually balances.

GYRO is a virtual robotics lab. Drag real components onto a chassis, wire every pin, tune a PID controller in real Arduino code — then drive a physics robot that stands on two wheels, wipes out, and gets back up. No hardware. No installs.

Start building — it's free Runs in your browser · works on iPad · nothing to install
01 · ASSEMBLE

Place real parts

Arduino Uno, MPU6050 IMU, L298N driver, gear motors, LiPo — each explained in plain language.

02 · WIRE

Wire every pin

SDA to A4, IN1 to D6 — the same wiring diagram you'd use on a physical build, with live feedback.

03 · PROGRAM

Tune the PID

Edit Kp, Ki, Kd in a real Arduino sketch and watch each term's contribution plotted live.

04 · DRIVE

Feel the physics

Hills, ice, launch ramps. The robot leans to accelerate — because that's how balancing robots move.

Control theory students can feel
