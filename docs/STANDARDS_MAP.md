# Curriculum → standards alignment (draft; validate with a pilot teacher)

## NGSS
| Lessons | Standard | How |
|---|---|---|
| c1–c5 (Circuits) | MS-PS2, HS-PS2 (forces/interactions), MS-ETS1-4 | Circuit function, power vs signal, iterative debugging of wiring |
| b1–b5 (Balance & PID) | HS-ETS1-2 (design solutions), HS-ETS1-4 (model/simulate) | Feedback control as engineering design; simulation-driven tuning |
| d1–d5 (Driving) | MS-PS2-2 (motion/forces) | Friction (ice), momentum (ramps), differential drive |
| e1–e5 (Engineering) | MS-ETS1-1..4, HS-ETS1-3 | Defining criteria, optimizing under constraints, full-system integration |

## CSTA (computer science)
- 2-AP-10 / 3A-AP-16 (algorithms, control structures): PID loop structure in the sketch
- 2-CS-02 (hardware/software interaction): pin mapping between sketch constants and physical wiring

## Common Core Math connections
- Ratios/rates (speed, wheel ω), signed numbers (tilt ±), graphs (PID term traces)

## Teacher one-pager talking points
- 20 auto-checked lessons ≈ 4–6 class periods; no hardware budget, no installs
- Every objective is verified against the live simulation, not a quiz
