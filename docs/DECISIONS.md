# Decision log

One line per irreversible/architectural decision, dated. Newest first.

- 2026-07-12 — Runtime robot switch = persist + reload (not in-place re-init): assembly/wiring/scene/sim resolve their RobotDef once at init (baked slot-ghost meshes, the tray DOM, `WiringManager.required`, the sim body), so a full teardown/rebuild would be fragile in a zero-build vanilla app. `switchRobot(id)` (js/robots/index.js) persists to `localStorage` (`sbl-active-robot`) and reloads; `bootActiveRobot()` reads it into state before `createScene`. `save.js` gates restore on matching `robotId`. Per-robot save slots deferred (single localStorage key today) — safe until a second robot is buildable.

- 2026-07-12 — Rover shipped as the second buildable robot (`available:true`). Design calls: (a) `RoverSim` **subclasses `BalanceSim`** rather than a fresh sim — reuses the proven arena + tuned arcade `fixedStep`, overriding only `build()` (flat chassis, 4 corner wheels) and `_pose()` (lean=0). Lowest-risk physics; the self-balancer is byte-unchanged. (b) Multi-instance parts (2 drivers, 4 motors) ride under single tray cards via a new slot `card` field, generalizing the old motor special-case in assembly.js — self-balancer motor slots tagged `card:'motor'` to keep identical behavior. (c) The two drivers **share** signal pins D6/D9 (left) / D10/D11 (right) because the Arduino only breaks out those four — real skid-steer, no phantom pins. (d) glossary.js maps instanced comp types (l298nF/motorFL/…) to base entries. (e) Per-robot save slots (`sbl-save-v1:<robotId>`, legacy key migrated) so switching robots doesn't clobber a build. (f) Serial boot/telemetry + guide + firmware header + sim HUD made robot-aware (rover hides the PID sliders / tilt sparkline). Deferred: rover-specific curriculum lessons (lessons still assume the self-balancer). Verified: `tests/rover.spec.js` (boots as rover, auto-wires 22-conn loom, RoverSim drives flat on 4 wheels) + all prior tests green.

  Earlier this day the rover was scaffolded (`available:false`, empty parts/slots) — that intermediate step is now superseded by the above.
